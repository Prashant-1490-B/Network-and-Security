# ARP Spoofing Detector Documentation

## Overview
The ARP Spoofing Detector is a tool designed to monitor network traffic and detect ARP spoofing attacks. ARP spoofing is a technique used by attackers to send fake ARP (Address Resolution Protocol) messages over a local area network. This can result in the redirection of network traffic, potentially compromising sensitive data.

## Architecture
The architecture of the ARP Spoofing Detector can be divided into the following components:

1. **Packet Sniffer**: Captures network packets in real-time to analyze ARP traffic. This component uses libraries such as `Scapy` to monitor network interfaces.
2. **ARP Analyzer**: Parses the captured packets to identify ARP requests and replies. It checks for inconsistencies, such as multiple MAC addresses linked to a single IP address.
3. **Alert System**: Sends notifications to network administrators upon detecting suspicious activity, ensuring timely intervention.
4. **Logging System**: Maintains logs of detected anomalies for future reference and analysis.

## Execution Flow
1. **Initialization**: The packet sniffer starts and sets the network interface to promiscuous mode, allowing it to capture all packets.
2. **Packet Capture**: Captured packets are sent to the ARP Analyzer for processing.
3. **Analysis**: The ARP Analyzer identifies ARP packets and analyzes their content to detect spoofing attempts.
4. **Detection**: If a threat is detected, the Alert System notifies administrators, while the Logging System records the event.

## Data Structures
- **ARP Packet Structure**: Each ARP packet has the following attributes:
  - **Sender MAC Address**: The MAC address of the sender.
  - **Sender IP Address**: The IP address of the sender.
  - **Target MAC Address**: The MAC address of the intended recipient.
  - **Target IP Address**: The IP address of the intended recipient.

- **Alert Structure**: The alert generated by the detection system includes:
  - **Timestamp**: Time of detection.
  - **Affected IP Address**: IP involved in the spoofing attempt.
  - **Detected MAC Addresses**: List of MAC addresses that caused the conflict.
